# 📦 Archive — Legacy & Prototype Files

This directory (`archive_unused/`) contains legacy prototype files and initial framework boilerplate (Next.js and Flask) retained for historical reference.

> [!NOTE]
> None of the files in this directory are part of the active **ScholarHub** application.

## Active Application Structure

The active production application is structured into two self-contained subdirectories at the repository root:

- **`frontend/`**: Active Vite + React 18 single-page application.
- **`backend/`**: Active Node.js + Express.js API server connected to Neon PostgreSQL.

## Archived Contents Overview

- **`app/`**, **`next.config.mjs`**, **`tsconfig.json`**, **`components.json`**, **`postcss.config.mjs`**, **`package.json`**, **`pnpm-lock.yaml`**: Initial Next.js 16 app router setup.
- **`components/`**, **`lib/`**, **`public/`**: Root component/utility/asset placeholders from the initial setup.
- **`app.py`**, **`templates/`**: Early Python Flask backend prototype.
- **`neon.ts`**: Early Neon configuration file.
